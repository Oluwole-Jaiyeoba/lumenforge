Validity Rule

A direct-overlap trial is valid only when decode starts first, SGLang queues a native load, its CUDA start/finish events report positive physical duration, at least the configured number of stream intervals intersects the observed load envelope, the load finishes, and decode finishes last.

Interpretation Boundary

The lightweight run uses SGLang's CUDA start/finish events and client-visible stream updates. A stream update is not assumed to equal exactly one generated token. The run proves software-visible temporal overlap, but it does not measure memory-controller bandwidth. A separate profiler run is required for physical bandwidth attribution, and its timing must not be pooled with this report.
