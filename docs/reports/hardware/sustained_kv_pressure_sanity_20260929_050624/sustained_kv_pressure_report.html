Proof Boundary

Each non-control trial must prove that every expected native load completed with positive CUDA duration inside the active decode. The sustained case also enforces a minimum total load duration and maximum gap between reloads.

Client-visible stream updates are not assumed to equal individual generated tokens. This lightweight report proves temporal overlap. Physical memory-bandwidth attribution still requires a separate profiler pass whose timings must not be pooled with these runs.
