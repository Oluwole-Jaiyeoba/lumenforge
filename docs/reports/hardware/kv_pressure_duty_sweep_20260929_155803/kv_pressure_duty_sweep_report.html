Interpretation Boundary

Each pressure run must prove every requested native reload completed with positive CUDA duration during active decoding. A recycle proof confirms that a donor was released from GPU memory while retaining a host-backed copy eligible for another native reload.

The measured CUDA-load share is the authoritative pressure value. The labels low, medium, and high describe the requested reload budget, not an assumed amount of physical contention.
