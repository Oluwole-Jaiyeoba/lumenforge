GPU Timeline

The two profiler traces shared the same clock base. During one five-second copy window, 499 GPU copy events were recorded. Of 56,762 SGLang kernels in that window, 56,483 overlapped a copy event in device time. The trace proves physical overlap, unlike the earlier SGLang-managed reload case that serialized the operations.

The profiled request timed out because profiling added severe overhead. Its trace is used only for overlap proof; every timing value above comes from the unprofiled paired run. NVIDIA lists the A10's memory as GDDR6, not HBM. These data do not yet isolate device-memory bandwidth from PCIe, copy-engine, or other shared-resource contention.
