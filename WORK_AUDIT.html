Agentic Work Audit

This lane checks when cache and GPU work happens across tool waits and replays. These runs validate event linkage on the pinned backend; they do not estimate production waste or prove a controller benefit. Warm and host cases run sequentially within each run. Reversing their order helps expose variability, but the small TTFT differences are not a controlled speed claim. Trace profiles have different overhead; do not compare TTFT across profiles as a workload result. Per-layer copies are not additional logical loads.
